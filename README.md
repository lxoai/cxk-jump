# 鸡你太美 · 跳一跳 🕺🏀

蔡徐坤版「跳一跳」小游戏。按住蓄力，松开起跳，跳准下一个方块！

**在线玩：** https://cdn.jsdelivr.net/gh/lxoai/cxk-jump@main/

## 玩法
- 按住屏幕（或空格）蓄力，松开起跳
- 每次起跳播放「鸡你太美」音效
- 跳空会听到「你干嘛～」并游戏结束
- BGM 为真·鸡你太美神曲循环，右下角可静音

## 🏆 排行榜
