# 鸡你太美 · 跳一跳 v3 🕺🏀🦁

蔡徐坤版「跳一跳」+ 马里奥走位 + 篮球对战！按住蓄力跳，站台对射，黑暗恐怖坤坤地图。

**在线玩：** https://lxoai.github.io/cxk-jump/

## 🎮 操作
- **← → / A D**：左右走位（躲子弹、调瞄准）
- **按住空格/↑（或点按屏幕）蓄力**，松开起跳（跳一跳玩法）
- **J / K / X**：发射篮球子弹（按住连发）
- 手机端：**左手◀▶走位（左下）· 右手🏀投篮（右下）**，拇指分区，已适配全面屏安全区
- **❤️ 三条命**：被撞/踩中/坠崖都会掉一条命并原地复活（短暂无敌闪烁），掉完三条才结束；复活会避开碎台子和狮子所在台

## 🦁 狮子座对战（蔡徐坤是狮子座）
- **每 100 分**：小狮子出现在前方台子上（HP 2，慢速篮球）
- **每 1000 分**：精英大狮子（HP 6，头戴王冠，双发子弹）——和红月同时降临
- **对射规则**：狮子向你发射篮球，你站台对射；**狮子活着不能跳上它的台子**（会被扑倒）；它的子弹只能**跳起来躲**（水平子弹走位追不上）
- 击退小狮子 **+50 分** / 大狮子 **+200 分** + 金币；弹簧弹射撞到狮子会把狮子撞退一格

## 🌕 红月模式（1000 分解锁）
- **所有得分双倍**：落台 / PERFECT / 击杀全部 ×2
- 愤怒坤坤脸的红色月亮 + 天空泛红 + 真爱粉投掷律师函
- 死亡结算随机附赠一句谐音梗（食不食油饼？露出鸡脚了吧…）

## 🌻 葵菜陷阱
- 台子边缘会长出愤怒的**葵菜**（蔡徐坤的菜），踩中=误食升天

## 🚗 谐音梗死亡：汽运 & 开艇
- **每 600 分**：汽车（标着"汽运"）或快艇（标着"开艇"）突然横穿台面
- 被撞飞=「汽运到头了…」/「开艇（开庭）了」——看到 ⚠ 警告跳起来躲

## 🌑🌕 黑暗恐怖坤坤地图 + 红月
- 黑夜星空 + 暗云迷雾 + 暗黑石台（发光描边），无缝循环无断片

## 🎯 核心玩法
- **真实物理**：落地不吸附，落哪算哪；台子中心有发光菱形标定 + 金色 PERFECT 脉冲区
- **得分**：跳跃 +5 基础分（碎台子 +15）/ PERFECT +25×连击倍率（最高 x5）
- 文字特效：站酷快乐体（ZCOOL KuaiLe，jsDelivr 分发）+ 弹入动画 + 辉光
- 特殊台子：🟢 弹簧 / 🪨 碎台 / ⇄ 移动 / 💰 金币
- **皮肤**：🕺 坤坤 / 🖤 乌鸡 / 🏀 篮球小子 / 🐔 金鸡（canvas 手绘）
- **四模式**：经典 / 限时 60s / 极速 / 每日（全球同图）
- **成绩卡** + 四榜排行榜
