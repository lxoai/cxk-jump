# 鸡你太美 · 跳一跳 v2 🕺🏀

蔡徐坤版「跳一跳」小游戏。按住蓄力，松开起跳，跳准下一个方块！

**在线玩：** https://lxoai.github.io/cxk-jump/

## 玩法
- 按住屏幕（或空格）蓄力，松开起跳
- 每次起跳播放「鸡你太美」音效
- 跳空会听到「你干嘛～」并游戏结束
- BGM 为真·鸡你太美神曲循环，右下角可静音

## 🎮 v2.0 玩法大礼包
- **真实物理**：落地不再自动滑到中心，落哪算哪，考验瞄准
- **中心标定**：每个台子有中心菱形标记，目标台子有金色 PERFECT 区，蓄力时带垂直瞄准虚线
- **PERFECT 判定**：落在金色区域 = PERFECT，金色粒子 + 音效 + 加分
- **连击倍率**：连续 PERFECT 叠加倍率（x1.5 / x2 / x2.5 … 最高 x5），断连重来
- **特殊台子**：
  - 🟢 弹簧台子：踩上自动弹射到下一个台子中心
  - 🪨 碎台子：踩上就裂，0.9 秒内不跳就塌
  - ⇄ 移动台子：左右横移，等它靠近再跳
  - 💰 金币台子：踩中赚金币
- **金币 & 皮肤**：金币解锁黑子 / 篮球 / 金坤坤皮肤
- **四大模式**：经典无尽 / 限时 60 秒 / 极速（方块狂缩）/ 每日挑战（全球同图，按天换图）
- **成绩卡**：死后一键生成成绩图分享到群里装杯

## 🏆 排行榜
- 全服实时排行榜（分经典/限时/极速/每日四个榜），游戏结束后提交昵称即可上榜
- 数据存储于 jsonblob.com（每 12 小时自动轮换迁移，分数长期保留）
