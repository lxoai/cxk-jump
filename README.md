# 鸡你太美 · 跳一跳 v2.1 🌑🕺🏀

蔡徐坤版「跳一跳」小游戏，**黑暗恐怖坤坤地图**。按住蓄力，松开起跳，跳准下一个方块！

**在线玩：** https://lxoai.github.io/cxk-jump/

## 玩法
- 按住屏幕（或空格）蓄力，松开起跳
- 每次起跳播放「鸡你太美」音效
- 跳空会听到「你干嘛～」并游戏结束
- BGM 为真·鸡你太美神曲循环，右下角可静音

## 🌑 v2.1 黑暗恐怖坤坤地图
- **黑夜星空**：深紫色夜幕 + 闪烁星空 + 暗云 + 底部迷雾（无缝循环，无断片）
- **暗黑石台**：紫墨色石砖 + 发光边框 + 竖向能量纹 + 发光中心标定，特殊台子各有专属辉光
- 台子中心有发光菱形标记，目标台子有金色 PERFECT 脉冲区，蓄力带垂直瞄准虚线

## 🌕 隐藏玩法：红月觉醒（1000 分解锁）
跳到 **1000 分**后红月升起——**坤坤愤怒的脸**挂在天上：
- 天空泛红、暗角加剧，顶部出现「🌕 红月降临」警示
- **真爱粉**随机出现在台子上方（💗+⚠ 预警），悬停后向下投掷**律师函**
- 被律师函碰到 = 游戏结束（「被律师函击中了！」）
- 只在站立时被偷袭，看准预警跳开即可躲避；频率会越来越密，红月是修罗场也是技术验证场
